# Начинки для вонтонів і спринг-ролів

Чотири начинки для покупного тіста для вонтонів і спринг-ролів. Кожної вистачає приблизно на 25–30 вонтонів або 10–12 спринг-ролів.

## 1. Вонтони зі свининою та креветками

Класична начинка для вонтонів — соковита, пружна й насичена. Варіть, готуйте на пару, обсмажуйте на сковороді або додавайте в суп.

| Інгредієнт | Кількість |
|---|---|
| Свинячий фарш (в ідеалі ~20% жиру) | 250 г |
| Сирі креветки, очищені, без кишечника | 150–200 г |
| Водяні каштани, дрібно посічені | 3–4 шт. |
| Зелена цибуля, тонко нарізана | 2 шт. |
| Світлий соєвий соус | 1 ст. л. |
| Устричний соус | 1 ч. л. |
| Кунжутна олія | 1 ч. л. |
| Вино шаосін або сухий херес | 1 ч. л. (за бажанням) |
| Імбир, натертий | 1 ч. л. |
| Цукор | 1/2 ч. л. |
| Сіль | 1/2 ч. л. |
| Білий перець | 1/4 ч. л. |
| Кукурудзяний крохмаль | 1 ч. л. |
| Холодна вода або курячий бульйон | 2–3 ст. л. |

### Приготування

1. **Підготуйте креветки:** змішайте з дрібкою солі та 1/2 ч. л. кукурудзяного крохмалю, промийте й ретельно обсушіть. Половину дрібно посічіть, решту наріжте більшими шматочками, щоб відчувалися в начинці.
2. **Приправте свинину:** змішайте фарш з усіма приправами, крім води. Енергійно мішайте в одному напрямку 2–3 хвилини, доки маса не стане липкою, схожою на пасту.
3. **Додайте воду** по ложці, щоразу добре вмішуючи — так начинка залишиться соковитою.
4. **Вмішайте** креветки, водяні каштани й зелену цибулю.
5. **Дайте постояти** в холодильнику 30–60 хвилин перед формуванням — це працює як маринад і робить начинку щільнішою, тож її легше загортати.

**Додатково за бажанням:** 1 невеликий зубчик часнику (натертий), кілька замочених сушених шиїтаке (дрібно посічених) або трохи дрібно натертої моркви для кольору. Ця начинка підходить і для спринг-ролів — додайте трохи нашаткованої капусти й бамбука.

## 2. Вонтони з яловичиною та водяними каштанами

Та сама техніка, що й для свинини з креветками, але з яловичиною та додатковою хрусткістю.

| Інгредієнт | Кількість |
|---|---|
| Яловичий фарш | 250 г |
| Водяні каштани, дрібно посічені | 4–5 шт. |
| Зелена цибуля, тонко нарізана | 2 шт. |
| Імбир, натертий | 1 ч. л. |
| Часник, натертий | 1 зубчик |
| Соєвий соус | 1 ст. л. |
| Кунжутна олія | 1 ч. л. |
| Вино шаосін або сухий херес | 1 ч. л. (за бажанням) |
| Цукор | 1/2 ч. л. |
| Білий перець | дрібка |
| Холодна вода або бульйон | 2–3 ст. л. |

### Приготування

1. Енергійно мішайте фарш із приправами в одному напрямку 2–3 хвилини, доки маса не стане липкою.
2. Поступово вмішайте воду.
3. Додайте водяні каштани й зелену цибулю.
4. Кладіть приблизно по 1 повній ч. л. на кожен листок тіста.

## 3. Спринг-роли з куркою, капустою та бамбуком

Легкі й хрусткі. Смажте у фритюрі або в аерогрилі.

| Інгредієнт | Кількість |
|---|---|
| Курка, дрібно нарізана або фарш | 250 г |
| Капуста, тонко нашаткована | 1/4 качана |
| Морква, нарізана соломкою або натерта | 1 шт. |
| Пагони бамбука (з банки), відціджені й нарізані тонкими смужками | 1/2 банки |
| Зелена цибуля, нарізана | 2 шт. |
| Часник, посічений | 2 зубчики |
| Імбир, натертий | 1 ч. л. |
| Соєвий соус | 1 ст. л. |
| Устричний соус (або хойсин) | 1 ст. л. |
| Кунжутна олія | 1 ч. л. |
| Білий перець | дрібка |
| Кукурудзяний крохмаль + вода | 1 ч. л. + 1 ст. л. |

### Приготування

1. Обсмажте курку, постійно помішуючи, до готовності, потім додайте часник та імбир.
2. Додайте овочі й смажте на сильному вогні 2–3 хвилини, помішуючи, — вони мають залишитися трохи хрусткими.
3. Приправте, потім вмішайте розведений крохмаль, щоб загустити сік.
4. **Перед загортанням повністю охолодіть начинку й відцідіть рідину.** Волога начинка дає розмоклі роли, які лопаються.
5. Щільно скрутіть і заклейте краї пастою з борошна та води.

## 4. Пряні трикутники з яловичиною, цибулею та червоним перцем

Варіація в стилі самоси. Використовуйте тісто для спринг-ролів, нарізане смужками й складене трикутниками, або тісто для вонтонів, складене навпіл. Смажте або запікайте.

| Інгредієнт | Кількість |
|---|---|
| Яловичий фарш | 250 г |
| Цибуля, дрібно нарізана | 1 шт. |
| Червоний солодкий перець, дрібно нарізаний | 1 шт. |
| Морква, дрібно нарізана | 1 шт. |
| Часник | 2 зубчики |
| Імбир, натертий | 1 ч. л. |
| Мелена зіра | 1,5 ч. л. |
| Мелений коріандр | 1 ч. л. |
| Гарам масала або карі | 1 ч. л. |
| Куркума | 1/2 ч. л. |
| Пластівці чилі або каєнський перець | до смаку |
| Сіль | до смаку |
| Лимонний сік | кілька крапель |
| Свіжа кінза | жменька (за бажанням) |

### Приготування

1. Розм'якшіть цибулю, потім додайте часник, імбир і спеції та готуйте 30 секунд.
2. Додайте яловичину й обсмажте до рум'янцю, добре розбиваючи грудочки.
3. Додайте перець і моркву й готуйте, доки вони не стануть м'якими, а маса — досить сухою.
4. Приправте сіллю й лимонним соком. Перед загортанням охолодіть.

## Соуси для вмочування

- **Вонтони:** соєвий соус, чорний або рисовий оцет, олія чилі та дрібка цукру.
- **Спринг-роли:** солодкий соус чилі.
- **Пряні трикутники:** йогурт із м'ятою або лаймом чи манговий чатні.

## Примітки

- **Тримайте тісто накритим** вологим рушником, поки працюєте — воно швидко висихає й тріскається.
- **Перевірте смак:** перш ніж ліпити всю партію, обсмажте або зваріть один пробний.
- **Не перекладайте начинки:** приблизно 1 повна ч. л. на вонтон, 2 ст. л. на спринг-рол.
- **Заморожування:** заморозьте сирі вонтони й роли на деку, потім перекладіть у пакети. Готуйте одразу із замороженого стану — додайте кілька хвилин.
