# Грибний паштет

Простий, насичений грибний паштет — цибуля, часник, петрушка й трохи вершків. Виходить близько 300 г, вистачить на закуску для 4–6 осіб.

## Інгредієнти

| Інгредієнт | Кількість |
|---|---|
| Гриби, нарізані скибочками або грубо порізані | 400–500 г |
| Цибуля, дрібно нарізана | 1 шт. |
| Часник, посічений | 2–3 зубчики |
| Жирні вершки | 3–4 ст. л. (або маскарпоне для багатшого, щільнішого паштету) |
| Свіжа петрушка | невеликий пучок |
| Вершкове масло або олія | 2 ст. л. |
| Сіль | до смаку |
| Чорний перець | щедро |

## Приготування

### 1. Розм'якшіть цибулю

Готуйте цибулю на вершковому маслі або олії на середньому вогні 5–8 хвилин, доки вона не стане м'якою, солодкуватою й золотистою.

### 2. Уваріть гриби

Додайте гриби й дрібку солі. Збільште вогонь і готуйте **10–15 хвилин**, час від часу помішуючи, доки **вся рідина не випарується** і гриби не почнуть підрум'янюватися. Це найважливіший крок — вологі гриби дають рідкий, прісний паштет.

### 3. Додайте часник

Вмішайте часник за хвилину до кінця смаження.

### 4. Збийте блендером

Дайте масі трохи охолонути, потім збийте блендером із вершками й петрушкою. Імпульсним режимом — для грубішої, «домашньої» текстури, або довше — для гладкої.

### 5. Приправте й охолодіть

Добре приправте — побільше чорного перцю, сіль за смаком. Охолоджуйте **щонайменше 1 годину**, щоб паштет загус; що довше він постоїть, то кращий смак.

## Подача

- На грінках або крекерах
- З хрусткими запеченими трикутниками з тіста для вонтонів
- З маринованими огірками або корнішонами, щоб урівноважити насиченість

## Примітки

- **Глибина смаку:** трохи соєвого або вустерського соусу додає пікантної глибини.
- **Зелень:** трохи чебрецю, обсмаженого разом із грибами, добре пасує.
- **Свіжість:** кілька крапель лимонного соку наприкінці освіжать смак.
- **Алкоголь:** трохи бренді або хересу під час смаження грибів — класичне доповнення.
- **Зберігання:** 3–4 дні в холодильнику. Якщо зберігаєте довше, залийте зверху тонким шаром розтопленого вершкового масла.
